# Vedio-Game-Sales-Analyisis-Dashboard
Interactive Power BI dashboard for analyzing video game sales, platforms, genres, publishers, and regional performance.
This project presents an interactive Power BI dashboard built using a video games sales dataset. The dashboard analyzes sales performance across different games, platforms, genres, publishers, and regions. It includes key KPIs, slicers, summary cards, and time-series visualizations to help users understand sales trends and business performance.
Tools Used: Power BI
Dataset: Video Games Sales Dataset
Key Analysis: Sales, regional performance, genres, platforms, publishers, and yearly trends.
